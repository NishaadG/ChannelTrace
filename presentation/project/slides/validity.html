Validity and limitations

What we claim, and what we do not

How we keep it honest

  • Code tested on journeys with a known answer
  • Credits sum to total conversions in every model
  • Bootstrap ranges on each channel's share
  • Models reported with and without leaking features
  • Tool measured: correctness, SUS survey, assistant accuracy

Limits we state openly

  • Attribution assigns credit; it does not prove cause
  • No ground truth exists, so we compare models, not crown one
  • GA360 is obfuscated and from one store
  • Criteo covers display ads only
  • Datasets differ in population and are never pooled
